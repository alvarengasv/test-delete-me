# test-delete-me

A [TCAdmin 3](https://docs.tcadmin.com) plugin repository.

Plugins live under `manifests/<category>/<name>/<version>/`, each described by a
`manifest.yaml` next to the files it installs. TCAdmin writes them here for you when you
use **Share** in the panel — see
[Sharing Plugins](https://docs.tcadmin.com/3/using-tcadmin/common/sharing-plugins).

To install from this repository, add its URL under **Settings → Plugin Repositories**.
